# ⚡ Wind Turbine Tycoon (Ultimate Edition)

Экономический 2D-тайкун ветропарка на чистой Java с яркой современной эстетикой, неоновыми эффектами, глубокой системой развития, динамическими погодными условиями, контрактами города, аркадными звуками, атмосферной фоновой музыкой и полноценным сохранением.

## 🎮 Все игровые возможности

### 1. 🚀 Система Эволюции Ветряков
* **Поэтапный прогресс моделей:** улучшение ветряка переводит его в новую продвинутую версию:
  `🔨 Малый` ($1k) ➔ `⚡ Средний` ($3.2k) ➔ `🌟 Гигант` ($9k) ➔ `🌊 Офшор` ($24k) ➔ `☀️ Гибрид` ($55k) ➔ `🌀 Квантовый VAWT` ($140k).
* **Справедливая экономика:** при улучшении вы платите только **разницу в цене** между моделями, сохраняя все ранее вложенные средства.
* **Быстрый апгрейд:** сетка выбора позволяет в один клик прыгнуть на любой более высокий тир с доплатой разницы.
* **Оверклокинг максимума:** по достижении финального «Квантового VAWT» открывается форсирование уровней (`⭐ Lv.2, Lv.3...`).
* **Демонтаж:** кнопка `🗑️ Снести` позволяет освободить слот с возвратом 50% стоимости ветряка.

### 2. 🔋 Накопители энергии и Биржа (Energy Market & Batteries)
* **Подстанция аккумуляторов:** накапливайте избыточную энергию при сильном ветре.
* **Защита города от блэкаута:** при штиле батарея автоматически поддерживает сеть и спасает контракты от провала.
* **Биржа и Пиковый спрос:** продавайте накопленный заряд на бирже. Во время **«Пикового спроса»** тариф взлетает в 2.5–3 раза, принося огромный куш!

### 3. 🔬 Дерево исследований (R&D Лаборатория)
* Зарабатывайте **очки науки (SP)** от работы ветропарка и критических кликов.
* **Аэродинамика лопастей (Lv.1-3):** +15% / +30% / +45% к выработке энергии.
* **Углепластиковые сплавы (Lv.1-3):** снижение скорости износа оборудования на 25%–75%.
* **Громоотвод и защита сети:** молнии больше не повреждают турбины, а мгновенно заряжают батарею (+350 кВт) и приносят премию мэрии ($1,500).
* **Радар раннего оповещения:** автоматически замедляет роторы при приближении торнадо, сводя урон к нулю.
* **Чертежи ремонтных дронов:** открывает производство автономных дронов.

### 4. 👑 Престиж / Ребёрт (IPO)
* Выходите на биржу и продавайте корпорацию инвесторам при достижении $100,000 и 6 вышек.
* Получайте постоянный несгораемый множитель: **+50% ко всем доходам и науке навсегда за каждый Rebirth**!
* Зеленые акции, корона престижа и сохранение всех технологий.

### 5. 🤖 Автономные ремонтные дроны
* Летающие квадрокоптеры патрулируют ветропарк.
* При повреждении турбин дроны самостоятельно подлетают к гондолам и чинят оборудование лучом электросварки с искрами.

### 6. 🏆 События, квесты и Эко-город
* **Случайные события:** Саммит ООН (субсидии x2), грозовые бури с молниями, торнадо.
* **Рост эко-города на горизонте:** с ростом выработанных кВт⋅ч город преображается от небольшого городка до сверкающего киберпанк-мегаполиса с садами на крышах и лазерными шпилями.
* **Система достижений:** 8 уникальных наград с денежными призами.

### 7. 🎨 Аудиовизуальные фишки и Крит-Кликер
* **Критический клик (💥 КРИТ x5):** шанс выбить пятикратный доход и очки науки при клике.
* **Живой мир:** стаи птиц в небе, капли дождя при грозе, неоновое LED-свечение лопастей ночью.
* **10 аркадных MIDI-звуков:** звуки постройки, звон монет, сирена бури, фанфары Rebirth, разряды молнии, арфа науки.
* **🎵 Фоновая музыка:** атмосферный саундтрек (`music/bgm.wav`) с бесшовным повтором и кнопкой переключения в верхнем меню.

## 🚀 Как запустить

### Вариант 1: Запуск готового `.exe` (Windows)
Запустите файл **`WindTycoon.exe`** или файл в папке `dist/WindTycoon/WindTycoon.exe`.

### Вариант 2: Запуск через скрипт `run.bat`
```bash
run.bat
```

### Вариант 3: Запуск кроссплатформенного `.jar`
```bash
java -jar WindTycoon.jar
```

### Вариант 4: Компиляция из исходников
```bash
javac -encoding UTF-8 WindTycoon.java
java -cp . WindTycoon
```

## 📱 Мобильная версия (iOS и Android)

В папке [`mobile/`](mobile/) реализован кроссплатформенный мобильный порт игры на **React Native / Expo** с поддержкой сенсорного управления, тактильной отдачи (Haptics), сохранения прогресса в AsyncStorage и полноэкранного 60 FPS 2D-поля.

### 📦 Скачать готовые файлы (GitHub Releases)
Благодаря настроенному GitHub Actions CI/CD, свежие сборки автоматически компилируются на серверах GitHub:
* **🤖 Android (.apk)**: скачайте файл `WindTurbineTycoon.apk` из раздела [Releases](https://github.com/usd8261-blip/wind-turbine-tycoon/releases) и установите прямо на смартфон.
* **🍎 iOS (.ipa)**: скачайте файл `WindTurbineTycoon.ipa` из раздела [Releases](https://github.com/usd8261-blip/wind-turbine-tycoon/releases) и установите через AltStore, Sideloadly, Scarlet или личный сертификат разработчика.

### 📲 Быстрый запуск на телефоне без установки (Expo Go)
1. Установите бесплатное приложение **Expo Go** на свой телефон:
   * [App Store (iOS)](https://apps.apple.com/app/expo-go/id982107779)
   * [Google Play (Android)](https://play.google.com/store/apps/details?id=host.exp.exponent)
2. В терминале запустите сервер разработки:
   ```bash
   cd mobile
   npm start
   ```
3. Отсканируйте появившийся QR-код камерой iPhone или приложением Expo Go на Android — игра мгновенно запустится на вашем устройстве!

### 🤖 Сборка нативного Android APK
Сгенерирован полноценный проект Android Studio в папке `mobile/android/`:
```bash
cd mobile/android
./gradlew assembleRelease
```
Либо облачная сборка через EAS:
```bash
npx eas-cli build -p android --profile preview
```

### 🍎 Сборка для iOS (IPA / TestFlight)
Сборка выполняется в облаке Expo EAS без необходимости локального Mac:
```bash
npx eas-cli build -p ios
```
