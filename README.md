# ⚡ Wind Turbine Tycoon (Roblox Edition)

Экономический 2D-тайкун ветропарка на чистой Java с яркой визуальной эстетикой в стиле Roblox, динамическими погодными условиями, контрактами города, аркадными звуками и полноценной системой сохранений.

## 🎮 Особенности игры

* **⚡ Активный Турбо-Кликер:** Кликайте по ветрякам, чтобы разгонять лопасти и набивать комбо **x2 / x3 / x5** с умножением всего дохода!
* **🏙️ Мегаполис и Контракты:** Снабжайте энергией растущий город на горизонте и выполняйте срочные заказы мэрии за крупные денежные вознаграждения.
* **🌙 Цикл Дня и Ночи:** Плавная смена суток. Ночью окна города вспыхивают лазурным и золотым светом, а лопасти турбин превращаются в светящиеся неоновые LED-полосы.
* **🌪️ Торнадо и Стихийные Бедствия:** Смерч может зародиться в регионе и с вероятностью 10% ударить по ветропарку, выводя оборудование из строя.
* **🛡️ Страховая Компания:** Оформите страховой полис за $10/мес, чтобы получить щедрую компенсацию ($800 за каждую поврежденную вышку) при ударе торнадо.
* **👷 Инженерная Служба:** Нанимайте техников для автоматического обслуживания и починки изношенных ветряков.
* **🔊 Встроенные MIDI-звуки:** Аркадные звуковые эффекты (звон монет, клики, сирена торнадо, победный джингл) без необходимости скачивать аудиофайлы.
* **💾 Полная Система Сохранений:** Автосохранение каждые 20 секунд и при закрытии окна. Прогресс сохраняется в `savegame.dat` и автоматически загружается при старте.

## 🚀 Как запустить

### Вариант 1: Запуск готового `.exe` (Windows)
Просто запустите файл **`WindTycoon.exe`** двойным кликом в папке проекта.

### Вариант 2: Запуск кроссплатформенного `.jar`
```bash
java -jar WindTycoon.jar
```

### Вариант 3: Компиляция из исходников
```bash
javac -encoding UTF-8 WindTycoon.java
java WindTycoon
```

## 🏗️ Автономная сборка (Standalone Bundle)
В папке `dist/WindTycoon/` собран полноценный автономный билд со встроенным Java Runtime — игра запускается на любом ПК с Windows даже без установленной Java!
